# CodeAlpha Task 3 – Task Automation

## Project Overview

This project is a Task Automation program developed in Python as part of the CodeAlpha Python Programming Internship.

The project automates repetitive tasks using Python, reducing manual effort and making everyday operations faster and easier.

## Features

- Automates repetitive tasks
- Reduces manual work
- Takes user input when required
- Performs tasks automatically
- Simple and easy-to-use Python program
- Handles basic errors

## Technologies Used

- Python
- Functions
- Loops
- Conditional Statements
- File Handling
- OS Module
- Automation Concepts

## How to Run

1. Install Python.
2. Open the project folder in VS Code or PyCharm.
3. Open the Python file.
4. Run the program.
5. Follow the instructions displayed in the terminal.
